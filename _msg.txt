feat(md/viewer): auto-detect large trajectories + fix tick label angle

- NMRMoleculeViewer: when a chosen trajectory file is >= 200 MB, estimate its
  frame count from the file size + topology atom count (per format: XTC ~6
  B/atom, TRR doubles, DCD floats) and, before parsing, ask the user whether
  to load every Nth frame (capped at ~2500 frames, same total time) or load
  everything. Confirmation modal with Cancel / Load everything / Reduce.
- SharedAnalysisTools: added shared AngledTick component (honours cfg.tickAngle
  from SharedChartStylePanel); was copy-pasted in CD/ssNMR/NMR sections.
- MDSections: the MD general-parameter charts (RMSD/RMSF/Rg/SASA + Energy) now
  apply the "Tick label angle" setting — previously they used plain ticks, so
  the Graphical Parameters angle control had no effect there.
