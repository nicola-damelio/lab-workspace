feat(md/nmr/docking): analysis params feed the per-atom table + shared viewer fixes on all pages

- MD per-atom table: new computed "analysis_*" layers (RMSF, RMSD, Rg, SASA,
  |SCD|) appear as columns once a calculation has stored values, so they are
  usable by the Per-Atom plot and the Condition plot:
  * "Calculate from trajectory" now writes RMSF per residue (to the backbone
    atoms) and system-level Rg / SASA / RMSD (pseudo-atoms "0-Rg", "0-SASA",
    "0-RMSD") into the active instance.
  * The membrane-profiles analysis writes the order parameters |SCD| (one
    pseudo-atom per lipid group + carbon, e.g. "0-POPC sn-1 C14").
  * Analysis pseudo-atoms are added to the Per-Atom / Condition atom selector.
  Examples enabled: RMSF per residue (Per-Atom plot), Rg vs temperature across
  instances (Condition plot), |SCD| per carbon vs temperature.
- NMR and Docking pages now pass resRenumber / onResRenumber (and Docking also
  atomRenames / onAtomRenames) to the shared 3D viewer, so the residue
  renumbering and the large trajectory / large structure handling behave the
  same as on the MD page.
